# Galeri Fotoğrafları

Bu klasöre aşağıdaki isimlerle fotoğraf ekleyin; landing sayfasında otomatik görünür:

| Dosya adı | Açıklama |
|-----------|----------|
| `ortak-alan.jpg` | Ortak alan |
| `calisma-odasi.jpg` | Çalışma odası |
| `etkinlik-alani.jpg` | Etkinlik alanı |
| `yemek-salonu.jpg` | Yemek salonu |

Desteklenen formatlar: `.jpg`, `.jpeg`, `.webp`, `.png`

Fotoğraf yoksa renkli gradient placeholder gösterilir.

Dosya yollarını değiştirmek için `src/config/landing.ts` dosyasını düzenleyin.
